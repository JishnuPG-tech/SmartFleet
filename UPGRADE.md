# TruckConnect / SmartFleet: Upgrade Specification

See full documentation at: [docs/UPGRADE.md](file:///C:/Users/JISHNU%20PG/Videos/SmartFleet/docs/UPGRADE.md)

### Key Sections:
1. **Core Logistics Features**: Milestone state machine, driver acceptance countdown (10m), zero-cost Google Maps telemetry bridge, 4-digit OTP & photo POD delivery verification, NDR exception handling, and trip manifests. *(SOS workflows excluded)*.
2. **Frontend UI Upgrades**: 
   - **Android Driver App**: Swipe-up active job HUD with landmark badges, 4-digit OTP keypad, camera POD overlay, digital signature canvas.
   - **Android Admin App**: Fleet pulse quick summary cards, rapid driver allocation bottom sheet, pinch-to-zoom mobile KYC reviewer.
   - **Web Operations Console**: Shiprocket-style lifecycle segmented tabs with pill counts, live trip stepper drawer, dynamic volumetric weight calculator, printable thermal labels & batch handover manifests.
3. **Execution Roadmap**: 5-phase delivery plan.
